# Widget Site noir (Delta Force)

Script Tampermonkey qui affiche uniquement l'**Atelier du Site noir** (production en cours + recommandations)
de https://www.playdeltaforce.com/events/hq/fr/index.html, avec un bouton **Rafraîchir**.

## Installation sur Android
1. Installer **Firefox** (Play Store), puis le module **Tampermonkey** (menu ⋮ → Modules complémentaires).
2. Ouvrir dans Firefox :
   https://raw.githubusercontent.com/saladetomateoignonchef/deltaforce-/claude/installation-claude-hjnsab/site-noir-widget.user.js
   → Tampermonkey propose l'installation → **Installer**.
3. Ouvrir https://www.playdeltaforce.com/events/hq/fr/index.html et se connecter (une seule fois).
4. Ouvrir https://www.playdeltaforce.com/events/hq/fr/index.html?widget
5. Menu ⋮ → **Ajouter à l'écran d'accueil**.

## Boutons
- **⟳ Rafraîchir** : recharge les infos.
- **Site** : affiche le site complet (pour se reconnecter) ; **Widget** pour revenir.
